Future ideas:
- Directory-level rolled-up status (folders with modified children get a badge).
- fsnotify-based auto-refresh when the worktree changes externally.
- Filter / search bar above the file list (name filter, "only dirty",
  "only untracked").
- File-level history — right-click a tracked file → "Show history for this
  file…" — filtered Repo History showing only commits that touched it.
- Search across history — filter the commit list by message substring or author.
- Show-ignored-files toggle for .gitignore debugging.
- Submodule indicator in the folder list (mark + click to open the submodule).
- Stash list (read-only) — Tools → Show Stashes → click to diff.
- Repo Health enrichment — add last-commit age, branch + tag counts to the
  existing stats + fsck dialog. (Stats + fsck verify + hints already
  shipped in v0.3.0.)
- Compare any two refs/commits — multi-select two commits in the Repo
  History view → "Compare these…" → existing read-only Historical Diff
  but cross-commit instead of vs-parent. Useful for "what changed
  between v1.0 and v1.5?" review work.
- Contributors list — read-only: names, commit counts, last-contribution
  date, lines-touched roll-up. Surfaces project/team shape.
- Branch / Tag / Remote list views — three small read-only listings (name
  + last commit + date). Pure display; deliberately no checkout / create /
  delete buttons (those would cross the explorer-vs-manager line).


Version 0.3.0 - May 15, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Repo History view — secondary window opened via View → Repo History… or
  the new History toolbar button next to "Tracked files". Two-pane layout:
  commit list on the left (subject + short-sha · author · relative time),
  per-commit detail on the right (full author/email/timestamp, wrapped
  commit message, list of files changed vs parent with A/M/D action codes).
  Click a file → opens the existing diff engine with both sides read-only
  ("Historical Diff" title) showing the parent's blob next to this commit's
  blob. Lazy load 200 commits at a time via "Load more commits". Binary
  blobs (NUL byte in first 8 KB) get a friendly dialog instead of garbage
  output.

- Last-commit info in the explorer's repo header — subject, author, and
  relative time shown italicised under the path / branch line. Shows
  "(no commits)" for a freshly-init'd repo.

- Recent folders list — File → Open Recent Folder shows up to the 10 most
  recently-opened folders (Open Folder dialog + drag-and-drop both feed it).
  Submenu rebuilds after each open so the order is always fresh. Stale
  paths are dropped automatically when clicked.

- History toolbar button in the main explorer window — same affordance as
  View → Repo History…, available without opening the menu.

- Commit-subject subtitle in diff pane heads — when a diff is opened from
  Repo History, each pane shows the commit subject directly under the
  SHA/date/path title so you can tell two side-by-side historical diffs
  apart at a glance. Hidden for non-history diffs to avoid an empty row.

- Historical Diff pane title enrichment — short SHA + ISO date (e.g.
  "319e5d3 2026-05-13: main.go") so parallel comparisons across multiple
  history windows are self-identifying.

- "Keep only one diff window open at a time" preference (default on).
  Opening a new diff closes any prior one to avoid window explosions when
  clicking through history. Diff windows with unsaved edits are kept open
  so work is never silently lost — single-window mode is best-effort.

- Hide .git from worktree listings by default — the .git directory no
  longer appears in the folder list. Use the "Tracked files" toolbar
  button (or View → Toggle Tracked Files / Folder View) to inspect what
  git is tracking. Preferences → "Show .git in folder listings" surfaces
  it again for users who want to drill into git's internals.

- Repo Health dialog — View → Repo Health… (also on the tray and as a
  new "Health" toolbar button). Shows object-database statistics (loose
  + packed object counts, on-disk sizes, pack count, garbage files)
  parsed from `git count-objects -v`, plus a `git fsck --no-progress`
  verify summary counting dangling, unreachable, missing, and broken
  objects with a sample list of the first 10. Closes with copy-paste-
  ready CLI hints — e.g. "287 loose objects — consider running
  `git -C <repo> gc`" — and a "Copy report to clipboard" button for bug
  reports / chat. Pure read-only: never invokes git gc, prune, or any
  other write operation; the user runs the suggested commands themselves
  in their CLI.

- Scan Dependencies… — View → Scan Dependencies… (also on the tray and
  as a new "Scan" toolbar button). Runs the dep-scan vulnerability
  scanner (the same skill that lives at ~/.claude/skills/dep-scan/)
  against the current folder, shows a non-modal progress dialog while
  it works, then renders the markdown report in a scrollable rich-text
  dialog with a Copy-to-clipboard button. Script resolution prefers the
  repo's own dep-scan.sh / dep-scan.ps1 (so teammates get a vendored
  copy on clone — see README_DEPSCAN.md) and falls back to the user-
  level skill install. Works on any folder, not just git repos — dep-
  scan walks for manifests across multiple ecosystems.

🔧 IMPROVEMENTS
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Symmetric read-only enforcement across Swap. Swapping sides in a Diff vs
  HEAD or Historical Diff keeps the read-only state attached to the
  immutable content; left/right now have independent leftReadOnly +
  rightReadOnly flags that travel with the buffer on swap.

- Diff factory signature extended (openDiffWindowWithPreload) to accept
  per-side subtitles and a separate rightReadOnly flag, enabling the new
  Historical Diff and pane-subtitle behaviours without disturbing the
  existing Compare Two Files… and Diff vs HEAD flows.

- Explorer's tray menu now includes Repo History… and Git Status Legend…
  alongside the existing entries for parity with the menu bar.

🐛 BUGS / FIXES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Secondary diff windows no longer hijack the explorer's menu bar.
  Previously on macOS, opening any diff from the explorer replaced the
  app-wide menu and never restored it after the diff was closed (Fyne's
  per-window SetMainMenu is a global NSApp.mainMenu set on macOS). The
  diff window's controls remain available via toolbar, right-click row
  menu, and keyboard shortcuts.


Version 0.2.0 - May 15, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Right-click context menu on each folder-view row:
    • Reveal in Finder / Explorer / file manager (cross-platform).
    • Copy path (absolute path to the clipboard).
    • Open in $EDITOR (honours $VISUAL, then $EDITOR; falls back to the
      OS' default open command).
    • Diff against HEAD… (see below).
    • git rm -f — remove from worktree + index (via go-git's wt.Remove).
    • git rm --cached — remove from index only, leaves the file on disk
      (shells out to `git`; pairs with manually adding a .gitignore entry).
  Items are enabled per-row based on whether the file is tracked,
  untracked, ignored, a directory, or .git.

- Diff against HEAD: opens the existing two-pane diff with the HEAD
  blob on the left (read-only) and the current worktree file on the
  right (editable). Edits flow only HEAD → worktree; the reverse
  direction is blocked. Left title shows "HEAD@<short-sha>: <rel>
  (read-only)". Read-only enforcement is symmetric — Swap left/right
  keeps the HEAD content protected on whichever side it now occupies.

- Preferences (File → Preferences…) reachable from the explorer too —
  theme, diff-view defaults (sync scroll, line numbers, visible
  whitespace), remember-window-size, and clear-recent-files. Same
  dialog as the diff window; works against app prefs whether or not a
  diff window is open.

🔧 IMPROVEMENTS
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Up button in the tracked-files view returns to the worktree view of
  the same folder (one logical level back) instead of walking out of
  the repo entirely. Tooltip changes between modes to reflect this.

- Human-readable Status column labels — "modified", "untracked",
  "ignored", "conflict", "modified (staged)", etc. — replacing the
  cryptic two-character `git status --short` codes. Hover the Status
  column header for a compact legend; View → Git Status Legend… opens
  the full reference dialog.

- Show All / Hide All Windows is now symmetric — Hide All snapshots
  which windows are currently visible and Show All restores exactly
  that set. Dialogs the user already dismissed before Hide All stay
  dismissed through the round-trip.

🐛 BUGS / FIXES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Update checker repointed at github.com/amarillier/KrankyBearGitExplorer.
  (Was still hitting the KrankyBearDiff repo and showing the wrong
  "latest version".)

- Default window size reduced to 825×600 (from 1100×800) — fits more
  comfortably on smaller screens; remember-window-size still wins
  when enabled.

- macOS Info-plist.txt placeholder and Windows Inno installer GUID
  aligned with the new bundle identity
  (com.github.amarillier.KrankyBearGitExplorer). Fresh Inno AppId so a
  Windows install of GitExplorer doesn't collide with an existing
  KrankyBearDiff install.

- compile-windows.sh referenced a non-existent
  Inno/KrankyBearDiff.iss; now points at Inno/KrankyBearGitExplorer.iss
  so Windows installer builds work end-to-end.

- Windows winres step rejected the 1024×1024 source icon ("must fit in
  256×256"); winres.json now points at the 64×64 and 256×256 sources
  so go-winres produces a proper multi-resolution group icon.

🏗️ INTERNALS
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Repo-wide rebrand sweep — build scripts, sync scripts, packaging
  metadata, binary names (kbdiff* → kbgitexplorer*), Linux package
  name (krankybear-diff → krankybear-gitexplorer), macOS .app bundle
  name (KrankyBearDiff.app → KrankyBearGitExplorer.app), all
  consistently KrankyBearGitExplorer now.

- Decoupled diff engine: runApp split into openDiffWindow(master) so
  the explorer can host the diff window as a secondary, and
  openDiffWindowWithPreload for the new "Diff against HEAD" path.
  setupMenus accepts setTray so secondary diff windows don't clobber
  the explorer's system tray.


Version 0.1.0 - May 13, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW (fork of KrankyBearDiff repurposed as a git repository explorer)
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Explorer main window: open a folder by file picker, drag-and-drop, or
  Cmd/Ctrl+O. Shows Name / Size / Modified / Status columns for the contents
  of the current folder.
- Repo header strip: current path, branch name, and clean vs dirty+untracked
  file counts when the folder is inside a git repository (via go-git/v5).
- .git row pinned at the top of the folder list. Clicking it switches to a
  tracked-files tree view of everything git is tracking inside the repo.
- "Tracked files" toolbar toggle and the Up arrow (while in tracked view)
  both return to the folder view.
- Human-readable status labels in the Status column (modified, modified
  (staged), untracked, ignored, deleted, renamed, conflict, …). Hover the
  Status header for a quick legend; View → Git Status Legend… for the full
  reference dialog.
- Drag a folder anywhere onto the window to open it (drop a file → opens
  its containing folder).
- Cross-platform: macOS 10.13+, Windows 10+, Linux (X11 / Wayland).
